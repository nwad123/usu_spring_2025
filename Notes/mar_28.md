# The Refiner

Explanation requirements:

- Utility: must consist of steps that are meaningful in the abstractor's 
  framework.
- Gererality: deductions generated by the refiner must be generalizable
  enough that we won't have to use the refiner for many many states.

We require that refiners produce Hoare logic proofs, which we get by 
translating an error path into a proof. We do this with craig 
interpolation (not SAT/SMT).

_Craig interpolants are precisely Hoare logic proofs for program 
paths in SSA form._

Feasible interpolation can be generated in polynomial time.

After converting to SSA, we _could_ use SAT / SMT to solve for sat,
but this is a really expensive application because if we would do 
that we would be reasoning about the whole path, which may be very 
long.

# Local Proofs 

Restrict every inference to use a local proof.

## Reverse Local Proof Example 

$$
\begin{align}
y_0 + 1 \le y_1 \le x_1 &\implies y_0 + 1 \le x_1 \\
y_0 + 1 \le x_1 \le y_0 &\implies y_0 + 1 \le y_0 \\
1 \le 0                 &\implies \false \\
\end{align}
$$
